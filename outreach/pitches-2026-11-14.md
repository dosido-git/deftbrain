# Outreach message bodies

One body per wave, plus sub-bodies where a wave needs more than one. In
`tracker.csv`, `wave` names each prospect's wave and `Body` names the body
below to send; `Subject` is already filled in for every row.

**How to send (from outreach@deftbrain.com, Thunderbird with the DeftBrain signature):**
- Send to `To`. If it's blank, use `contact_form`, or skip the row if
  `contact_notes` says `Contact NEEDED` or `Replacement NEEDED`.
- Each `<<column>>` is a column in `tracker.csv`; drop that row's value in as
  is. `which_link`, `replacement_name` and `other_dead_links` are written as
  finished phrases. `other_dead_links` is often blank: then delete that line.
- Replace `[name]`. The signature supplies DeftBrain's name, links and email.
- Log `date_sent`, with `follow_up_date` 7 days later.
- Priority 3 rows are long shots (old blog posts, vendors, a court).
