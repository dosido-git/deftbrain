# Outreach message bodies

Waves 1 and 2 were sent with their own bodies (kept below as sent). Everyone
else (waves 3–9) gets the same message, Body 3. In `tracker.csv`, `wave` is
now just the sending batch, and `Subject` is already filled in for every row.

**How to send (from outreach@deftbrain.com, Thunderbird with the DeftBrain signature):**
- Send to `To`. If it's blank, use `contact_form`, or skip the row if
  `contact_notes` says `Contact NEEDED` or `Replacement NEEDED`.
- Each `<<column>>` is a column in `tracker.csv`, written as a finished phrase.
  `broken_desc` says what the dead link pointed to; `offer_desc` describes the
  DeftBrain page in `replacement_deftbrain` (the state table or the tool).
- The signature supplies DeftBrain's name, links and email.
- Log `date_sent`, with `follow_up_date` 7 days later.
- Priority 3 rows are long shots (old blog posts, vendors, a court).
